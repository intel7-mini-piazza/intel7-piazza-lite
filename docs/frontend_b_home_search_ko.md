# Piazza-lite 프론트엔드 B 핸드오프 — 홈 / 질문 목록 / 검색

## 1. 역할

당신은 4시간짜리 교실 프로젝트 **Piazza-lite**의 프론트엔드 중  
**홈 화면 / 질문 목록 / 검색 기능**을 담당합니다.

Piazza-lite는 Stack Overflow / Piazza를 단순화한 형태의  
**교실용 검색 가능한 Q&A 지식 공유 서비스**입니다.

백엔드는 별도의 담당자가 FastAPI로 구현하고 있습니다.

당신의 핵심 역할은 다음과 같습니다.

> **백엔드 API에서 질문 목록을 받아 화면에 보기 좋게 출력하고, 검색 기능을 구현한다.**



# 5. 필수 기능

## A. 질문 목록 불러오기

다음 API를 호출합니다.

```http
GET /api/questions
```

예상 응답:

```json
[
  {
    "id": 1,
    "title": "FastAPI WebSocket이 새로고침 시 끊깁니다",
    "author": "Sean",
    "tag": "Python",
    "answer_count": 3,
    "solved": true,
    "created_at": "2026-08-21T10:30:00"
  }
]
```

각 질문을 카드 또는 목록 형태로 출력합니다.

최소 표시 정보:

- 제목
- 작성자
- 태그
- 답변 개수
- 해결 여부

---

## B. 질문 검색

검색창을 구현합니다.

사용자가 예를 들어:

```text
servo
```

라고 검색하면 다음 API를 호출합니다.

```http
GET /api/questions?search=servo
```

그리고 결과 목록을 다시 화면에 출력합니다.

검색 실행 방식은 다음 중 하나면 충분합니다.

- 검색 버튼 클릭
- Enter 키 입력

실시간 검색은 선택사항입니다.

---

## C. 질문 상세 페이지로 이동

질문 카드를 클릭하면  
프론트엔드 D가 구현하는 질문 상세 페이지로 이동합니다.

예시 URL:

```text
question.html?id=12
```

예시 코드:

```js
window.location.href = `question.html?id=${question.id}`;
```

---

## D. 질문 작성 페이지로 이동

`질문하기` 버튼을 누르면  
프론트엔드 C가 구현하는 질문 작성 페이지로 이동합니다.

예시:

```text
ask.html
```

# 7. 권장 구현 순서

## Step 1

먼저 가짜 질문 데이터를 사용해 정적인 HTML 화면을 만듭니다.

## Step 2

질문 데이터를 불러오는 함수를 만듭니다.

예:

```js
async function loadQuestions(search = "") {
    // API 호출
    // JSON 변환
    // 질문 목록 렌더링
}
```

## Step 3

질문 배열을 화면에 출력하는 함수를 만듭니다.

```js
function renderQuestions(questions) {
    // 기존 목록 비우기
    // 질문 카드 생성
}
```

## Step 4

검색 기능을 연결합니다.

## Step 5

질문 클릭 시 상세 페이지로 이동하도록 합니다.

## Step 6

질문하기 버튼을 연결합니다.

# 11. PPT 준비 파트

개발과 동시에 아래 발표 내용을 간단히 준비합니다.

## 문제점

- 구두 답변은 남지 않는다
- 채팅 속 답변은 시간이 지나면 묻힌다
- 동일한 질문이 반복된다

## 해결책

- 질문과 답변을 지속적으로 저장
- 검색 가능한 Q&A
- 교실 지식이 누적됨

준비하면 좋은 것:

- 문제점 bullet
- 해결책 bullet
- 완성된 Home/Search 화면 스크린샷
